Key Ideas

  1. The multiplication sign can be omitted in algebra.
  2. Numbers are usually written before variables.
  3. Repeated multiplication can be written using indices.
  4. When multiplying expressions, multiply the coefficients first.
  5. When multiplying powers with the same base, add the indices.
  6. When dividing powers with the same base, subtract the indices.
  7. A power outside brackets applies to every factor inside the brackets.
  8. Be careful with negative numbers.
  9. Always write answers in simplified form.
