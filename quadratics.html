Understanding Quadratics

이차함수의 기본 형태와 그래프의 핵심 요소

Key Idea

이차함수는 보통 y = ax² + bx + c 형태로 나타냅니다. 그래프는 parabola(포물선)이며, a의 부호가 그래프가 위로 열리는지 아래로 열리는지를 결정합니다.

vertex 꼭짓점axis of symmetry 대칭축roots / x-intercepts 근 / x절편y-intercept y절편
Worked Example

For y = 3x², state the direction of opening and the vertex.

Since a = 3 > 0, the parabola opens upward. The vertex is (0, 0).
Level 1 · Easy

Q1. For y = -2x² + 5, does the parabola open upward or downward?

Downward, because a = -2 < 0.
02

Three Forms of a Quadratic

standard, factorised, vertex form

Key Ideas

Standard: y = ax² + bx + c

Factorised: y = a(x-r₁)(x-r₂)

Vertex: y = a(x-h)² + k

Worked Example

For y = (x - 2)(x - 5), identify the roots.

The roots are x = 2 and x = 5.
Level 2 · Medium

Q2. Write down the vertex of y = 2(x - 3)² - 4.

(3, -4)
03

Completing the Square

standard form을 vertex form으로 바꾸기

Worked Example

Rewrite x² + 6x + 5 in completed-square form.

x² + 6x + 5 = (x + 3)² - 9 + 5 = (x + 3)² - 4
Level 2 · Medium

Q3. Rewrite x² + 8x + 7 in completed-square form.

Half of 8 is 4. Start with (x + 4)².
(x + 4)² - 9

Graphing Quadratics

vertex, intercepts, symmetry를 이용해 그래프 그리기

Key Idea

그래프를 그릴 때는 vertex, axis of symmetry, x-intercepts, y-intercept를 먼저 찾으면 정확하고 빠릅니다.

Level 3 · Hard

Q4. Sketch y = x² - 4x + 3. Label the roots, vertex and axis of symmetry.

Roots: 1 and 3. Vertex: (2, -1). Axis of symmetry: x = 2.
05

Solving Quadratic Equations

factorising, quadratic formula, graph-based solving

Key Idea

이차방정식은 인수분해, quadratic formula, 또는 그래프의 x-intercepts를 이용해 풀 수 있습니다.

Level 1 · Easy

Q5. Solve x² - 2x - 15 = 0.

(x + 3)(x - 5) = 0, so x = -3 or x = 5.
06

The Discriminant

근의 개수와 parameter 문제

Key Idea

For ax² + bx + c = 0, the discriminant is Δ = b² - 4ac. If Δ > 0 there are two real roots, if Δ = 0 one repeated root, and if Δ < 0 no real roots.

Level 3 · Hard

Q6. The graph of f(x) = x² + kx + 9 touches the x-axis at exactly one point. Find k.

“Touches” means the discriminant equals zero.
k² - 36 = 0, so k = ±6.
07

Finding a Quadratic Equation

주어진 점, 근, vertex로 식 찾기

Level 3 · Hard

Q7. A quadratic has roots 2 and 5 and passes through (0, 10). Find its equation.

Let y = a(x - 2)(x - 5). Using (0,10): 10 = 10a, so a = 1. Therefore y = (x - 2)(x - 5).
08

Intersections & Tangency

두 그래프의 교점과 접선 조건

Key Idea

두 그래프의 교점은 두 식을 같게 놓아 찾습니다. 한 점에서 접하면 resulting quadratic의 discriminant가 0입니다.

Level 4 · Application

Q8. Determine the values of m for which y = x² and y = mx + 4 are tangent.

x² = mx + 4 → x² - mx - 4 = 0. The discriminant is m² + 16, which is always positive, so there are no real values of m for tangency.
09

Quadratic Inequalities

그래프와 부호를 이용한 범위 해석

Level 3 · Hard

Q9. Solve x² - 5x + 6 < 0.

(x - 2)(x - 3) < 0, so 2 < x < 3.
10

Modelling & Optimization

실생활 상황을 이차함수로 모델링하기

Context Example

The height of a ball is modelled by h = -5t² + 20t, where h is in metres and t is in seconds.

The ball is on the ground when h = 0: -5t(t - 4) = 0, so t = 0 or t = 4. It returns to the ground after 4 seconds.
Level 4 · Application

Q10. For h = -5t² + 20t, find the maximum height.

The vertex occurs at t = -b/(2a) = 2. Then h(2) = 20. Maximum height = 20 m.
