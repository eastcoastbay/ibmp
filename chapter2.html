2.1

식의 전개

분배법칙을 이용해 괄호를 없애기

Distributive Law · 분배법칙

a(b + c) = ab + ac

a(b - c) = ab - ac

Example

3(x + 4)

3 × x + 3 × 4 = 3x + 12
2.1.2

Expanding Two Brackets

두 괄호의 모든 항을 서로 곱한 뒤 동류항 정리

(x + a)(x + b) = x² + (a + b)x + ab

(x - a)(x - b) = x² - (a + b)x + ab

(x + a)(x - b) = x² + (a - b)x - ab

Example

(x + 3)(x + 5)

x² + 5x + 3x + 15 = x² + 8x + 15
Example

(x - 2)(x - 7)

x² - 7x - 2x + 14 = x² - 9x + 14
Example

(x + 4)(x - 6)

x² - 6x + 4x - 24 = x² - 2x - 24
2.1.3

Perfect Square Formulae

완전제곱 공식

(a + b)² = a² + 2ab + b²

(a - b)² = a² - 2ab + b²

Example

(x + 5)²

x² + 2(x)(5) + 5² = x² + 10x + 25
Example

(x - 3)²

x² - 2(x)(3) + 3² = x² - 6x + 9
2.1.4

Difference of Two Squares

두 제곱의 차 공식

(a + b)(a - b) = a² - b²

Example

(x + 4)(x - 4)

x² - 4² = x² - 16
2.2.1

공통인수가 있는 경우 인수분해

모든 항에 공통으로 들어 있는 인수 먼저 묶기

ab + ac = a(b + c)

ab - ac = a(b - c)

Example

6x + 9

3(2x + 3)
Example

8y - 12

4(2y - 3)
2.2.2

이차식의 인수분해

전개의 역과정을 이용해 두 괄호로 나타내기

x² + (a + b)x + ab = (x + a)(x + b)

x² - (a + b)x + ab = (x - a)(x - b)

x² + (a - b)x - ab = (x + a)(x - b)

ax² + bx + c = (px + q)(rx + s), where pr = a, qs = c, and ps + qr = b

a² - b² = (a + b)(a - b)

Example

x² - 8x + 15

곱해서 15, 더해서 -8이 되는 두 수는 -3, -5이므로 (x - 3)(x - 5)
Example

x² - 2x - 15

곱해서 -15, 더해서 -2가 되는 두 수는 3, -5이므로 (x + 3)(x - 5)
Example

2x² + 7x + 3

pr = 2, qs = 3, ps + qr = 7을 만족시키면 (2x + 1)(x + 3)

Check: 2x² + 6x + x + 3 = 2x² + 7x + 3
2.2.3

삼차식의 인수분해

합의 세제곱과 차의 세제곱 공식

a³ + b³ = (a + b)(a² - ab + b²)

a³ - b³ = (a - b)(a² + ab + b²)

Example

x³ + 8

x³ + 2³ = (x + 2)(x² - 2x + 4)
Example

x³ - 27

x³ - 3³ = (x - 3)(x² + 3x + 9)
★

Key Ideas

꼭 기억해야 할 12가지

  1. Expanding means removing brackets by multiplying each term inside the brackets.
  2. Use the distributive law to expand expressions such as a(b + c) and a(b - c).
  3. When expanding two brackets, multiply every term in the first bracket by every term in the second bracket.
  4. Like terms should be collected after expanding.
  5. Perfect square expressions have a middle term of 2ab or -2ab.
  6. The difference of two squares has the form a² - b².
  7. Factorising is the reverse process of expanding.
  8. When factorising, always check for a common factor first.
  9. To factorise x² + bx + c, find two numbers that multiply to c and add to b.
  10. To factorise ax² + bx + c, find factors that multiply to a and c, and give the correct middle term.
  11. Sum and difference of cubes follow special formulae and cannot be factorised like simple quadratics.
  12. Always check factorisation by expanding the brackets again.
